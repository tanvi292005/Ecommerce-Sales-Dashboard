# Ecommerce-Sales-Dashboard
Ecommerce Sales Dashboard:
A dynamic ,interactive Power BI dashboard designed to analyze ecommerce sales performance, customer behavior, profitability, and product trends through data-driven visualizations.

Description:
businesses monitor key performance indicators such as sales, profit, quantity sold, and average order value. It enables stakeholders to identify sales trends, evaluate product performance, understand customer purchasing behavior, and make informed business decisions.

Tech Stack:
The dashboard was built using the following tools and technologies:
📊 Power BI Desktop – Dashboard development and data visualization.
🔄 Power Query – Data cleaning and transformation.
🧮 DAX (Data Analysis Expressions) – KPI calculations and custom measures.
📁 Excel Dataset – Data source for analysis.
